Privacy Policy

1. Introduction

This Privacy Policy explains how our game (“we”, “our”, or “us”) collects, uses, and protects your information. By using our game, you agree to this policy.

2. Information We Collect

We collect the following types of information to improve your gameplay experience and save progress:

  • Gameplay progress and performance
  • Game settings and preferences
  • Device information for technical support
  • Usage statistics for performance optimization

Important: We do not collect any personal information such as name, email, phone number, or location.

3. Details of Collected Variables

The following variables are collected and stored securely in Firebase:

Category Variable Name(s) Description
Scene Progress Scene_1 ... Scene_8 Whether each scene is completed
Time Records m_Scene1TimeRecord ... m_Scene8TimeRecord Time taken to complete each scene
Settings QualityLevelIndex, FrameRate, AudioVolume, ControlMode, WheelInverted, SensorInverted, SteeringSensitivity User preferences for graphics, controls, and audio
Gameplay Mode SelectedMapIndex, StoryModeFlag, FreeModeFlag, SelectedVehicleIndex Which map, mode, and vehicle the player selected
Level Statistics level_1_PlayCount ... level_8_PlayCount, Level_PlayCount_Total Number of times each level was played and total play count
Time Spent level_1_TimeSpent ... level_8_TimeSpent, level_TimeSpent_Total Total time spent in each level and all levels combined
App Usage gameOpenedCount Number of times the game was opened

4. Data Storage and Firebase

All collected data is stored securely using Google Firebase services. Data is used only for game functionality, analytics, and improving gameplay experience.

6. Consent for Personalized Ads
